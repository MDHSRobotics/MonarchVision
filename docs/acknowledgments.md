# Acknowledgments and Third-Party Software
MonarchVision makes use of several open-source and commercial tools developed
by organizations and members of the FIRST Robotics Competition community.
We gratefully acknowledge their work.

## AdvantageKit and AdvantageScope

[AdvantageKit](https://docs.advantagekit.org/) and
[AdvantageScope](https://docs.advantagescope.org/) are developed by
Littleton Robotics, FRC Team 6328 (Mechanical Advantage).

AdvantageKit provides the logging, telemetry, and replay framework used by
this project. AdvantageScope is used for visualization and analysis of robot
and simulation data.

AdvantageKit and AdvantageScope are separate projects and are not affiliated
with or endorsed by this documentation project.

## WPILib

[WPILib](https://wpilib.org/) provides the core software libraries and
development tools used by FIRST Robotics Competition teams.

This project uses WPILib for robot programming, simulation, geometry,
kinematics, NetworkTables, and other robot functionality.

## PhotonVision

[PhotonVision](https://photonvision.org/) is an open-source vision system
designed for FIRST Robotics Competition.

This project uses PhotonVision for AprilTag-based field localization and
vision processing.

## Limelight

[Limelight](https://limelightvision.io/) provides vision hardware and
software designed for robotics applications.

This project uses Limelight cameras for AprilTag localization and
object detection.

## PathPlanner

[PathPlanner](https://pathplanner.dev/) is an open-source motion planning
and autonomous navigation tool for FIRST Robotics Competition.

This project uses PathPlanner for autonomous path generation and
pathfinding.

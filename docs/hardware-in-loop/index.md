# Hardware in the Loop

Hardware-in-the-loop testing uses real cameras and coprocessors while the robot drivetrain and other mechanisms remain simulated.

## Sections

- [Field vision](field-vision.md)
- [Object detection](object-detection.md)

## Goals

- Test real camera networking
- Test NetworkTables communication
- Validate real camera measurements
- Exercise production robot code without a complete robot
- Compare simulated and real vision behavior

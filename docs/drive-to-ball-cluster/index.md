# Drive to Ball Cluster

## Objective

Explain how the robot chooses a useful group of balls and drives toward it with the rear of the robot facing the target.

## Topics to cover

- Converting detections to field positions
- Grouping balls into clusters
- Scoring clusters
- Selecting a target cluster
- Choosing a target point
- Rear-facing pickup geometry
- Translation and heading control
- Preventing target switching and oscillation
- Stopping and driver override behavior

## Demonstration videos

Add videos showing cluster selection and robot movement.

## Lessons learned

Describe why cluster targeting was selected instead of simply driving to the closest ball.

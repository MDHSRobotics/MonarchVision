# FRC Vision Processing and Simulation

This site documents the development of an FRC vision and simulation system, including robot simulation, vision processing, replay, hardware-in-the-loop testing, and vision-assisted driving.

## Main topics

- AdvantageKit and AdvantageScope
- Drive simulation
- Replay
- Simulating field vision
- Simulating object detection
- Driving to a ball cluster
- Hardware-in-the-loop testing
- Vision hardware setup
- Software architecture

## Purpose

The goal is to preserve not only the final implementation, but also:

- Why each approach was selected
- How the components fit together
- How the system was tested
- Problems encountered and their solutions
- Videos and logs demonstrating the results
